# FUNC-001 文書削除（説明用の部分仕様）

REQ-001: 管理者が自社の文書を削除できる。他テナントの文書を削除できない。

目的: 不要な文書を管理対象から除外する。
入力: 信頼済みの操作者のテナント・管理者属性、対象文書 ID。
出力: DELETED / DENIED / NOT_FOUND。
事前条件: 呼び出し側で操作者の属性が真正と確認され、文書の集合が一貫している。
不変条件: INV-001 文書の削除は同一テナントの管理者にのみ許可する。
事後条件: 存在する自社文書を管理者が指定した場合、当該文書だけが削除され DELETED を返す。それ以外は状態を変更しない。存在しない文書には NOT_FOUND、存在するが認可されない文書には DENIED を返す。
検証: TEST-001〜004 (`test_document_delete.py`)。

例示のため不在と認可拒否を区別する。本番では存在の漏えい、認証、同時実行、監査、永続化等を別途設計・評価すること。
